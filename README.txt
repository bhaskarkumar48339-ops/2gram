2Gram PWA
=========
This is a lightweight mobile web app prototype.

Important:
- For full PWA install/offline service-worker behavior, it should be served over HTTPS (or localhost).
- Opening index.html directly from a file manager may work for the basic UI, but service-worker installation can be blocked by Android Chrome.
- Posts and profile are stored locally in the browser.
- This is not yet a real multi-user social network.
